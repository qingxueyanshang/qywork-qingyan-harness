# Word（docx）做法要点

## 流程

1. 修改已有文件时先调用 `read_office`，取得文档结构与 `sha256`。
2. 用 `write_file` 在工作区中写入 Python 制作脚本。
3. 用 `write_office` 执行脚本：脚本写出工作副本 → 按请求回填目录页码 → 结构检查 → 渲染 → 提交到正式路径。结果中包含每个文件的页数、检查项与各阶段状态。
4. 用 `view_office` 查看页面：一次可取多页；表格密集、含图表或小字的区域用 `region` 取局部。
5. 发现问题时修改脚本，再次执行 `write`。修改后重新查看改动的页；分页发生变化时，其后受影响的页也要重新查看。

生成成功不等于合格：交付前查看每一页，并写明看到的内容。

## 脚本 API

脚本运行时提供全局变量 `office`（也可用 `from qyoffice import office` 导入）：

- `office.output(路径)`：已声明的输出对应的工作副本路径，脚本写入该路径。修改已有文件时，工作副本中已是原文件的内容。
- `office.inputs`：已声明的输入路径列表。
- `office.workspace`：工作区根目录。
- `office.figure(宽cm, 高cm)`：按最终插入尺寸创建 matplotlib 画布，已设置中文字体；返回 `(fig, ax)`。
- `office.app("docx")`：取得新启动的 WPS / Word 实例的原生对象，用于只有办公软件才能完成的读取或计算。每次调用都启动一个新实例，一个实例只打开一个文件。不要用它另存文件：WPS 另存文件，以及 WPS 文字在同一实例中再次打开文件，都会写入用户的最近文档与账号打开记录。

可使用 python-docx、lxml、Pillow、matplotlib 的完整 API，也可以直接修改 OOXML。

## 中文字体

python-docx 设置 `font.name` 只改变西文字体，中文字体还需设置 `eastAsia`：

```python
from docx.oxml.ns import qn

def east_asia(element, name):
    """element 取样式的 style.element，或文字块的 run._r。"""
    element.get_or_add_rPr().get_or_add_rFonts().set(qn("w:eastAsia"), name)

east_asia(doc.styles["Normal"].element, "宋体")
east_asia(doc.styles["Heading 1"].element, "黑体")
```

正文与各级标题样式都需设置。检查项 `east_asia_font_missing` 表示默认样式未设置东亚字体。

## 图表与图片

- 图按插入尺寸设计：先确定插入宽度（通常等于版心宽度，A4 默认约 16 cm），用 `office.figure(16, 9)` 生成图，插入时使用同一宽度 `Cm(16)`。这样图中 9 pt 的文字在文档中仍为 9 pt。
- 不要先绘制大图再缩小插入：文字随之缩小，无法辨认。
- 数据图保留坐标轴、刻度与单位；标题、脚注放在图外的正文中，或使用图面坐标（`fig.text`）定位，不要用数据坐标定位文字。
- 图号、图题与正文引用从同一份数据生成，避免图文不一致。
- 检查项 `image_wider_than_text` 表示图片宽于版心。

## 表格

- 使用原生表格，表头行设为「标题行重复」（行属性 `w:tblHeader`），需要时把「允许跨页断行」设为否（`w:cantSplit`）。
- 数字列右对齐、统一小数位；列宽按内容分配。

## 目录与页码

- 目录使用 TOC 域。python-docx 没有对应的接口，可按以下方式插入：

```python
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

def add_toc(paragraph, levels="1-3"):
    for kind, text in (("begin", None), ("instr", f'TOC \\o "{levels}" \\h \\z \\u'),
                       ("separate", None), ("text", "目录"), ("end", None)):
        r = OxmlElement("w:r")
        if kind == "instr":
            el = OxmlElement("w:instrText"); el.set(qn("xml:space"), "preserve"); el.text = text
        elif kind == "text":
            el = OxmlElement("w:t"); el.text = text
        else:
            el = OxmlElement("w:fldChar"); el.set(qn("w:fldCharType"), kind)
        r.append(el)
        paragraph._p.append(r)
```

- 标题使用内置「Heading 1/2/3」样式（或带大纲级别的样式）：目录只收录这些标题。
- 需要页码时，`write` 带 `update_toc=true`：工具以只读方式导出页面，按标题所在页回填目录页码。未找到标题时，目录保留原结果并在结果中报告。
- 回填的条目按级别套用样式「TOC 1」「TOC 2」「TOC 3」，文档中没有这些样式时条目使用正文样式。python-docx 的默认模板不含这些样式，需要指定字体、缩进时先创建：`doc.styles.add_style("TOC 1", WD_STYLE_TYPE.PARAGRAPH)`。
- 自动编号（多级列表）显示的章节号会写入目录条目；整段为隐藏文字的标题不进入目录。
- 页眉页脚中的 PAGE 域由 Word / WPS 在显示时计算，不需要回填。目录以外的 PAGEREF / REF 域不回填。
- 不要在 settings 中设置 `updateFields`：Word 打开文件时会询问是否更新域（检查项 `update_fields_on_open`）。

## 修改已有文件

- 先 `read`：之后 `write` 同一路径时，工具以读取时的版本为准，文件在此期间被其他程序修改时返回冲突，不覆盖。
- 在工作副本上只修改需要修改的段落、表格、图片，不要整篇重新排版；python-docx 无法识别的对象（公式、SmartArt、嵌入对象）保持原样。
- 交付的文件就是脚本写出的文件，工具不会让办公软件另存该文件。
- 文档属性由脚本设为真实作者：python-docx 默认写入作者 `python-docx` 与备注 `generated by python-docx`（检查项 `library_metadata`）。用户未提供作者时清空这些字段（`doc.core_properties.author`、`comments`），不要写入工具名。

## 边界

- 带宏的文件（.docm 等）一律拒绝打开。
- 渲染、目录回填需要 Windows 上的 WPS 或 Microsoft Office；未安装时这两个阶段返回 unavailable，不能视为已查看页面。
- 技能中写明的其他产品的执行方式（artifact-tool、soffice、shell 导出脚本等）仅作为做法参考，执行一律使用 write_office。技能已生成供 write_office 执行的脚本时（例如它输出的 `office_job.py`），直接把该脚本交给 write_office，不要改写技能的代码。

## 最小示例

```python
import io

from docx import Document
from docx.oxml.ns import qn
from docx.shared import Cm, Pt

doc = Document()
normal = doc.styles["Normal"]
normal.font.name = "Times New Roman"
normal.font.size = Pt(12)
normal.element.get_or_add_rPr().get_or_add_rFonts().set(qn("w:eastAsia"), "宋体")
doc.add_heading("第一章 概述", level=1)
doc.add_paragraph("正文内容。")
fig, ax = office.figure(16, 8)
ax.bar(["一季度", "二季度"], [120, 150])
ax.set_ylabel("收入（万元）")
fig.tight_layout()
buf = io.BytesIO()
fig.savefig(buf, format="png", dpi=200)
doc.add_picture(buf, width=Cm(16))
doc.save(office.output("报告.docx"))
```
