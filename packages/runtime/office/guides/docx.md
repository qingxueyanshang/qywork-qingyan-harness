# Word（docx）做法要点

## 流程

1. 有原文件先 `read_office`：拿到结构和 `sha256`。
2. 用 `write_file` 写一个 Python 制作脚本，放在工作区里。
3. `write_office` 执行脚本：脚本写出工作副本 → 按请求回填目录页码 → 结构检查 → 渲染 → 提交到正式路径。结果里有每个文件的页数、检查项和各阶段状态。
4. `view_office` 看页：一次可取多页；密集的表格、图表、小字用 `region` 取局部。
5. 看出问题就改脚本，再 `write`。改完重看改动的页；分页变了，后面受影响的页也要重看。

生成成功不等于合格：交付前每一页都要看过，并写下看到了什么。

## 脚本 API

脚本运行时有全局变量 `office`（也可 `from qyoffice import office`）：

- `office.output(路径)`：声明过的输出对应的工作副本路径，脚本写这里。修改已有文件时，工作副本里已经是原文件的内容。
- `office.inputs`：声明过的输入路径列表。
- `office.workspace`：工作区根目录。
- `office.figure(宽cm, 高cm)`：按最终插入尺寸建 matplotlib 画布，已设好中文字体；返回 `(fig, ax)`。
- `office.app("docx")`：取一个产品新起的 WPS / Word 原生对象，用于只有办公软件才能做的读取或计算。每次调用都新起一个实例，一个实例只打开一个文件，不要用它另存文件：WPS 另存、WPS 文字在同一实例里再次打开文件，都会写进用户的最近文档与账号打开记录。

python-docx、lxml、Pillow、matplotlib 的完整 API 都可以用，也可以直接改 OOXML。

## 中文字体

python-docx 设 `font.name` 只改西文字体，中文还要设 `eastAsia`：

```python
from docx.oxml.ns import qn

def east_asia(element, name):
    """element 取样式的 style.element，或文字块的 run._r。"""
    element.get_or_add_rPr().get_or_add_rFonts().set(qn("w:eastAsia"), name)

east_asia(doc.styles["Normal"].element, "宋体")
east_asia(doc.styles["Heading 1"].element, "黑体")
```

正文与各级标题样式都要设。检查项 `east_asia_font_missing` 表示默认样式没有设。

## 图表与图片

- 图按插入尺寸设计：先定插入宽度（通常等于版心宽度，A4 默认约 16 cm），用 `office.figure(16, 9)` 出图，插入时用同一个宽度 `Cm(16)`。这样图里 9 pt 的字在文档里就是 9 pt。
- 不要先画一张大图再缩小插入：字会跟着缩小到看不清。
- 数据图保留坐标轴、刻度和单位；标题、脚注放在图外正文里或用图面坐标（`fig.text`），不要用数据坐标定位文字。
- 图号、图题和正文引用从同一份数据生成，避免图文不一致。
- 检查项 `image_wider_than_text` 表示图片比版心宽。

## 表格

- 原生表格，表头行设为「标题行重复」（行属性 `w:tblHeader`），需要时设「允许跨页断行」为否（`w:cantSplit`）。
- 数字列右对齐、统一小数位；列宽按内容分配。

## 目录与页码

- 目录用 TOC 域。python-docx 没有现成接口，可以这样插入：

```python
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

def add_toc(paragraph, levels="1-3"):
    for kind, text in (("begin", None), ("instr", f'TOC \\o "{levels}" \\h \\z \\u'),
                       ("separate", None), ("text", "目录"), ("end", None)):
        r = OxmlElement("w:r")
        if kind == "instr":
            el = OxmlElement("w:instrText"); el.set(qn("xml:space"), "preserve"); el.text = text
        elif kind == "text":
            el = OxmlElement("w:t"); el.text = text
        else:
            el = OxmlElement("w:fldChar"); el.set(qn("w:fldCharType"), kind)
        r.append(el)
        paragraph._p.append(r)
```

- 标题用内置「Heading 1/2/3」样式（或带大纲级别的样式），目录才找得到。
- 需要页码时 `write` 带 `update_toc=true`：工具只读导出页面，按标题所在页回填目录页码。标题找不到时目录保留原结果并报告。
- 回填的条目套用样式「TOC 1」「TOC 2」「TOC 3」（按级别），文档里没有这些样式时条目用正文样式。python-docx 的默认模板没有它们，要定字体、缩进时先建：`doc.styles.add_style("TOC 1", WD_STYLE_TYPE.PARAGRAPH)`。
- 自动编号（多级列表）显示的章节号会带进目录条目；整段都是隐藏文字的标题不进目录。
- 页眉页脚里的 PAGE 域由 Word / WPS 显示时计算，不需要回填。目录以外的 PAGEREF / REF 域不回填。
- 不要在 settings 里设 `updateFields`：Word 打开文件时会弹出是否更新域的询问（检查项 `update_fields_on_open`）。

## 修改已有文件

- 先 `read`：之后 `write` 同一路径时，工具以读到的版本为准，文件在此期间被别处改过就返回冲突、不覆盖。
- 在工作副本上只改需要改的段落、表格、图片，不要整篇重排；python-docx 不认识的对象（公式、SmartArt、嵌入对象）保持原样。
- 交付件就是脚本写出的文件，工具不会让办公软件另存它。
- 文档属性由脚本设成真实作者：python-docx 默认会写入作者 `python-docx` 与备注 `generated by python-docx`（检查项 `library_metadata`）。用户没有给作者时清空这些字段，不要写入工具名。（`doc.core_properties.author`、`comments`）

## 边界

- 带宏的文件（.docm 等）一律拒绝打开。
- 渲染、目录回填需要 Windows 上的 WPS 或 Microsoft Office；没有时这两个阶段返回 unavailable，不能当成看过页面。
- 技能里写的其他产品的执行方式（artifact-tool、soffice、shell 导出脚本等）只当做法参考，执行一律用 write_office；技能附带的专属代码要改写成这里支持的 Python。

## 最小示例

```python
import io

from docx import Document
from docx.oxml.ns import qn
from docx.shared import Cm, Pt

doc = Document()
normal = doc.styles["Normal"]
normal.font.name = "Times New Roman"
normal.font.size = Pt(12)
normal.element.get_or_add_rPr().get_or_add_rFonts().set(qn("w:eastAsia"), "宋体")
doc.add_heading("第一章 概述", level=1)
doc.add_paragraph("正文内容。")
fig, ax = office.figure(16, 8)
ax.bar(["一季度", "二季度"], [120, 150])
ax.set_ylabel("收入（万元）")
fig.tight_layout()
buf = io.BytesIO()
fig.savefig(buf, format="png", dpi=200)
doc.add_picture(buf, width=Cm(16))
doc.save(office.output("报告.docx"))
```
