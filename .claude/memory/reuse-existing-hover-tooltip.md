description: 截断文字需要显示全文时沿用原有的悬停提示（data-tip），不新增点击浮层等交互形式
metadata:
  type: feedback
---

界面上需要补充显示截断内容（报错全文、长命令、长路径）时，使用应用已有的悬停提示：在元素上设置 `data-tip`，
由 `Tooltip.tsx` 统一显示。不新增点击弹出的浮层、按钮或其他交互形式。

**Why:** 2026-10-27 用户问「点击悬浮里面出详细的这种模式是否能解决」，并附上原有悬停提示的截图作为参照；
实现成点击后弹出浮层（新组件、新样式）后被否决：「为什么不用原来的悬停格式」。用户提到的「这种模式」指截图中已有的格式。

**How to apply:** 用户以截图或现有界面为参照提出做法时，按参照的现有形式实现；确需新增交互形式时先说明并询问。
与 [[probe-ui-with-isolated-instance]] 配合核对实际显示。
