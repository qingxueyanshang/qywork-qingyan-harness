画布生成卡发给模型的提示词以卡片上可见的文字为准。手写的「@图片N」与所选型号的引用写法（如 hongcheng 的「@ImageN」）不一致时，不在编译阶段静默改写。2026-10-21 曾在 `compilePrompt` 中加入按型号改写手写编号的逻辑，被用户否决并已撤回。

**Why:** 用户的原话是「看不见的转化，没啥用」。看不见的改写使卡片文字与实际发送内容不一致，而且只覆盖已记录写法的型号，未适配的渠道仍会失败。

**How to apply:** 用户提出的方案是：已适配的型号由 agent 直接按型号写法书写，写法不一致时在提交前提示；未适配的型号报错后由 agent 换用候选写法重写，确认有效后记入该型号的配置。这一方案需要新增写入型号配置的入口，截至 2026-10-21 尚未获批实施。素材芯片 `@[卡片]` 按型号写法编译属于既有设计，不在此列。相关的技能侧规则（每份素材只在【素材职责】@一次）见 AIGC创作 工作区的 flow-video-script v6.1.0。
